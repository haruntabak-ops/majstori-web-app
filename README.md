# Majstori Web App

## Opis projekta

Web aplikacija koja omogućava majstorima da kreiraju nalog, uređuju svoj profil i definišu usluge koje nude, dok posjetioci mogu pretraživati majstore prema hijerarhijski organizovanim kategorijama usluga i pregledati njihove kontaktne podatke. Administrator upravlja kategorijama majstorluka i korisničkim nalozima.

Aplikacija integriše vanjski geocoding API koji na osnovu unesenog grada pronalazi geografske koordinate, omogućavajući prikaz lokacije majstora na mapi.

## Tehnologije

- Frontend: HTML, CSS i JavaScript
- Backend: PHP i FlightPHP
- Baza podataka: MySQL
- Pristup bazi: PDO
- Komunikacija: REST API i AJAX
- Autentifikacija: JWT

## Korisničke uloge

- Posjetilac: pretražuje majstore i pregledava njihove profile.
- Majstor: uređuje svoj profil i definiše usluge koje nudi.
- Administrator: upravlja kategorijama majstorluka i korisničkim nalozima.

## Status projekta

Projekat je u početnoj fazi razvoja. Funkcionalnosti će se implementirati postepeno kroz predviđene projektne milestonee.
